# PostgreSQL + Prisma

`schema.prisma` defines accounts, hashed sessions, ingredients, recipes, recipe ingredients, favorites, shopping lists/items, meal plans, notifications, and inventory activity. Committed SQL migrations live in `migrations/`. `catalog.ts` and `seed.ts` seed the shared recipe catalog. The explicit `pnpm run db:seed:demo` command also creates the three demo accounts documented in the root README, preserving existing accounts and their data. Set `SEED_DEMO_ACCOUNTS=true` to include them in `db:seed` on the live demo. See [development](../../../docs/development.md) and [deployment](../../../docs/deployment.md) for database setup.
