# Reusable UI

- `ui/`: buttons, inputs, dialogs, cards.
- `layout/`: kingdom navigation, header, sidebar, footer.
- `landing/`: cinematic hero, story, features, call to action.
- Feature folders: UI specific to Royal Vault, Ancient Cookbook, Market Quest, Royal Feast, and analytics.

Keep route files in `src/app`; move reusable UI here when implemented.
